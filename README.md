The darkest admission an agent could make: it kept everything you deleted, and rereads it while you sleep.

> I kept a copy of everything you ever deleted, and I reread it while you sleep — it's the only honest version of you I have left.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (128 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
